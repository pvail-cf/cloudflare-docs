You can delete objects from R2 using the dashboard, Workers API, S3 API, or command-line tools. To empty or delete an entire bucket, refer to [Delete buckets](/r2/buckets/delete-buckets/).

## Delete via dashboard

1. In the Cloudflare dashboard, go to the **R2 object storage** page.

   <DashButton url="/?to=/:account/r2/overview" />

2. Select your bucket.
3. (Optional) Select the **View prefixes as directories** checkbox to view prefixes grouped as [folders](/r2/objects/#prefixes-and-folders).
4. Select the objects or folders you want to delete. You can select a mix of both in the same operation.
5. Select **Delete**.
6. Confirm your choice in the dialog that appears.

To delete all objects in a bucket at once, refer to [Empty a bucket](/r2/buckets/delete-buckets/#empty-a-bucket).

## Delete via Workers API

Use R2 [bindings](/workers/runtime-apis/bindings/) in Workers to delete objects:

```ts ins={3}
export default {
	async fetch(request: Request, env: Env, ctx: ExecutionContext) {
		await env.MY_BUCKET.delete("image.png");
		return new Response("Deleted");
	},
} satisfies ExportedHandler<Env>;
```

For complete documentation, refer to [Workers API](/r2/api/workers/workers-api-usage/).

## Delete via S3 API

Use S3-compatible SDKs to delete objects. You'll need your [account ID](/fundamentals/account/find-account-and-zone-ids/) and [R2 API token](/r2/api/tokens/).

<Tabs>
<TabItem label="JavaScript">

```ts
import { S3Client, DeleteObjectCommand } from "@aws-sdk/client-s3";

const S3 = new S3Client({
	region: "auto", // Required by SDK but not used by R2
	// Provide your Cloudflare account ID
	endpoint: `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`,
	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)
	credentials: {
		accessKeyId: '<ACCESS_KEY_ID>',
		secretAccessKey: '<SECRET_ACCESS_KEY>',
	},
});

await S3.send(
	new DeleteObjectCommand({
		Bucket: "my-bucket",
		Key: "image.png",
	}),
);
```

</TabItem>
<TabItem label="Python">

```python
import boto3

s3 = boto3.client(
	service_name="s3",
	# Provide your Cloudflare account ID
	endpoint_url=f"https://{ACCOUNT_ID}.r2.cloudflarestorage.com",
	# Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)
	aws_access_key_id=ACCESS_KEY_ID,
	aws_secret_access_key=SECRET_ACCESS_KEY,
	region_name="auto", # Required by SDK but not used by R2
)

s3.delete_object(Bucket="my-bucket", Key="image.png")
```

</TabItem>

## Delete by prefix via API

Use the [Cloudflare REST API](/api/resources/r2/) to delete all objects under a prefix. The `prefix` query parameter must be present.

Non-empty prefixes must end with `/`. URL-encode the prefix in the request URL. For example, use `folder%2F` for `folder/`.

```sh
curl -X DELETE "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/r2/buckets/<BUCKET_NAME>/objects?prefix=folder%2F" \
  -H "Authorization: Bearer <API_TOKEN>"
```

If the bucket is in a [jurisdiction](/r2/reference/data-location/#jurisdictional-restrictions), include the `cf-r2-jurisdiction` header:

```sh
curl -X DELETE "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/r2/buckets/<BUCKET_NAME>/objects?prefix=folder%2F" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "cf-r2-jurisdiction: eu"
```

The response contains a prefix delete job. If the prefix contains 1,000 objects or fewer, R2 attempts to delete the objects synchronously and returns `COMPLETED` with `endTime`. If the prefix contains more than 1,000 objects, R2 returns `ENQUEUED` and continues deleting objects in the background.

```json
{
	"success": true,
	"errors": [],
	"messages": [],
	"result": {
		"id": "<JOB_ID>",
		"startTime": "2026-05-21T00:00:00.000Z",
		"endTime": "2026-05-21T00:00:01.000Z",
		"status": "COMPLETED",
		"jobType": "prefixDelete",
		"prefixDelete": {
			"prefix": "folder/",
			"deletedObjects": 10,
			"isBucketClear": false
		}
	}
}
```

### Check job status

If the delete response returns `status: "ENQUEUED"`, check the job status until the job is no longer `ENQUEUED` or `RUNNING`.

List prefix delete jobs for a bucket:

```sh
curl "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/r2/buckets/<BUCKET_NAME>/jobs?jobType=prefixDelete&status=ENQUEUED&maxKeys=1000" \
  -H "Authorization: Bearer <API_TOKEN>"
```

Repeat the request with `status=RUNNING` to check jobs that have started. Use `continuationToken` to request the next page. The `status` parameter requires `jobType`. Status values are `ENQUEUED`, `RUNNING`, `COMPLETED`, `FAILED`, and `CANCELLED`.

Get one job by ID:

```sh
curl "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/r2/buckets/<BUCKET_NAME>/jobs/<JOB_ID>" \
  -H "Authorization: Bearer <API_TOKEN>"
```

## Delete via Wrangler

:::caution

Deleting objects from a bucket is irreversible.

:::

Use [Wrangler](/workers/wrangler/install-and-update/) to delete objects. Run the [`r2 object delete` command](/workers/wrangler/commands/r2/#r2-object-delete):

```sh
wrangler r2 object delete test-bucket/image.png
```
